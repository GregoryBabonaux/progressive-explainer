## progressive-explainer

When the user asks you to explain a topic, asks how something works, or asks for a document they will read to understand something, invoke the `progressive-explainer` skill and follow it: short first document, one running analogy, progress checklist at the end.

When the user replies with a number from a progress checklist, invoke `progressive-explainer` again and cover that subtopic.

Code changes, commits, pull requests and quick factual answers do not use this skill.
