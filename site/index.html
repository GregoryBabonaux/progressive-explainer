Explanations you can actually follow.

progressive-explainer is a skill for AI agents. It turns long answers into a short overview with one running analogy, then lets you pick what to dig into, one piece at a time.

npx skills add GregoryBabonaux/progressive-explainer
Claude Code plugin

Works with Claude, Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot and any agent that reads SKILL.md.

Correct, complete, and impossible to follow

Ask an AI agent how something works and you often get a wall of text. If you have trouble with attention or focus, you lose the thread halfway, and the answer is wasted.

Question: Why does my coffee get cold so fast?

Usual answer

The cooling of a hot beverage results from several superimposed heat transfer mechanisms, including natural convection at the liquid-air interface, whose coefficient depends on the Rayleigh number, infrared radiation governed by the Stefan-Boltzmann law, conduction through the cup wall according to its thermal diffusivity, and evaporation, whose latent heat, combined with the saturation vapor pressure, explains why in practice, and subject to ambient conditions, it is worth noting that…

With progressive-explainer

Your coffee loses its heat through the top, mostly by evaporating.

Picture your cup as a house with no roof: the heat escapes through there first.

In one sentence: put a lid on it.

  • 1. Overview 🟢
  • 2. Does the cup matter? 🟢
  • 3. Milk: does it help? 🟡

Two stages: a short overview, then you choose

The first document is 250 to 400 words, always in the same order.

  1. One-sentence answer

    The point, in under 20 words, before anything else.

  2. The frame

    What this is about, why it matters, who decides.

  3. How it works

    2 to 4 short sections, with one analogy running through all of them.

  4. A diagram, if useful

    5 elements at most, every arrow labelled.

  5. One-sentence recap

    Something you could repeat to someone else.

  6. A progress checklist

    Subtopics sorted from easy to advanced. Reply with a number: the agent covers it with the same analogy and ticks the box.

The rules that make it readable

  • The conclusion comes first. Every section opens with it, in bold. Headings and bold text alone give you the essentials.
  • One analogy for the whole topic. No juggling between three metaphors.
  • No setting without its location. Which file or tool it lives in, and how to check it works.
  • One number per point. Names and sources go at the end, not in the middle of a sentence.
  • Casual body, neutral headings. No hook, no suspense, no filler.
  • Your language. The agent answers in the language you write in.

Every rule lives in a single SKILL.md file. Edit it to tune them.

Install

  1. Install the skill

    /plugin marketplace add GregoryBabonaux/progressive-explainer
    /plugin install progressive-explainer@progressive-explainer

    Recommended. Adds the skill and an /explain <topic> command.

    npx skills add GregoryBabonaux/progressive-explainer

    For Codex, Cursor, Gemini CLI, GitHub Copilot, OpenCode and others. Installs in the project, or globally with -g.

    npx progressive-explainer-cli skills --yes

    Copies the skill to ~/.agents/skills and ~/.claude/skills.

    Download the skills/progressive-explainer folder as a zip, then upload it in the Skills section of Claude's settings.

  2. Optional: use it for every explanation in a project

    npx progressive-explainer-cli init

    By default you call the skill when you want it. This adds a rule to AGENTS.md (and CLAUDE.md or GEMINI.md if your project uses them) so the agent uses it whenever you ask for an explanation. Nothing is written until you add --yes.

  3. Check

    npx progressive-explainer-cli doctor
